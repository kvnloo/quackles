# RFC-001 — Canonical 1GP source compiler

**Status:** POST-PRODUCTION / BLOCKED BY RFC-000  
**Tracking:** #44  
**Predecessor:** #43

## Thesis

The first beautiful frame and sharpest inspection frame should come from the **same accepted master** whenever possible.

```text
canonical Blender scene
-> accepted Cycles master
-> immutable master hash
   -> resident hero derivative
   -> intermediate levels
   -> highest inspection tiles
   -> audit crops / metrics / receipt
```

A future compiler should provide the equivalent of `compile-inspection-source`, `audit-source`, and `promote-source`. Provenance should include source ID, Blender revision, camera/render contract, master hash, plate derivation, pyramid derivation and evidence receipt.

## Blue first

Do not color-correct the rejected historical Blue 1GP into compliance. Render a new candidate from the accepted Blue scene, derive all inspection representations from it, and compare against the accepted ~201MP control. Repeat other themes only after Blue wins.

## Promotion gate

No source becomes production until semantic crops preserve authored identity, registration/color continuity passes frozen acceptance, no visible source/LOD pop exists, performance is no worse than the control on required devices, and lineage is reproducible.
