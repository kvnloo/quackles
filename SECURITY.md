# Security

- Do not open issues with secrets, pairing tokens, API keys, or private transcripts.
- Report vulnerabilities privately to @kvnloo via [GitHub private vulnerability reporting](https://github.com/kvnloo/quackles/security/advisories/new). Do not file a public CVE-shaped issue unless the project says so.
- Unknown authority, undeclared privileged capability, and unsigned receipts fail closed when the project has a validator.
- This file never authorizes autonomous merge.
