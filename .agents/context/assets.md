# Art / native simulator assets

Look: sequence manifests, `lib/sim/native/asset-manifest.json`, asset preparation/register scripts and the assigned art lane's evidence. Art acceptance is independent of code tests.
Run: native preparation pin validation, relevant asset/sequence contracts and a static build; use the lane's visual acceptance evidence when touching pixels.
Protect: canonical .blend/source textures, owner-locked appearance, hashes, public/private boundary. Do not regenerate art, publish asset hosts, rewrite manifests or run GPU renders as incidental cleanup. Preserve-first audit precedes deletion; regenerable is not the same as disposable.
